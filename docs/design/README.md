## 总原则

1. **桌面端保持现有体验**，不因手机改造而破坏宽屏布局。
2. **手机端做成 App 壳**：顶栏精简 + 底栏导航 + 安全区 + 大触控区。
3. **视觉统一**：继续使用现有暗色信用卡风（金 / 青 / 深蓝），不另起一套品牌色。
4. **网页实现、App 体感**：可滚动长页 + 固定底栏，后续可加「添加到主屏幕」。
